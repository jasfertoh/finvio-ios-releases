# Finvio for iPhone — releases

Builds of Finvio for sideloading with [SideStore](https://sidestore.io). The source
code lives in a separate private repository; this repo only hosts the `.ipa` files
(under Releases) and the SideStore source.

**Add the source in SideStore** → Sources → **+**:

```
https://raw.githubusercontent.com/jasfertoh/finvio-ios-releases/main/apps.json
```

Then install Finvio from it; new versions appear as updates in My Apps.
